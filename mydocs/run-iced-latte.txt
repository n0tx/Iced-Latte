# Toko Kopi Iced Latte Backend
1. menyiapkan terminal cli linux

2. masuk ke directory project Iced-Latte
$ cd Iced-Latte

3. set requirement project java25 dan maven 3.9.14
$ sdk env
karena di existing linux system menggunakan java 17
sdk env akan membaca .sdkmanrc (java25, maven 3.9.14) dan load di terminal session

4. check java dan maven version
$ java --version
openjdk version "25" 2025-09-16
$ mvn --version
Apache Maven 3.9.14 (996c630dbc656c76214ce58821dcc58be960875b)

5. jalankan docker untuk arsitektur project (postgres, redis, minio, minio-init)
$docker compose up -d postgres redis minio minio-init

6. aktifkan config .env pada project untuk terminal session
$ set -a; source .env; set +a;

7. maven build test compile
$ mvn clean test-compile

8. menjalankan Iced Latte spring boot
$ mvn spring-boot:run

# Setup Bayar Stripe
mendapatkan secret key dari stripe, sk_test
mendapatkan webhook key dari stripe, wh_key
key di set dan ada di .env
install stripe cli agar localhost bisa di hubungin
atau menerima notifikasi dari stripe
jika backend menerima notifikasi pembayaran dari midtrans,
maka backend kemudian akan mengirimkan notifikasi ke user
yang baru bayar belanjanya

- regitster website stripe dan masuk ke sandbox
- get secret_key dan wh_key
- install dan jalankan stripe cli di localhost
untuk listen dan menerima request dari stripe

# Setup Bayar Midtrans

atau set ip public di localhost menggunakan ngrok
set alamat ngrok + url backend webhook di midtrans 
website config agar dapat dihubungi oleh midtrans sewaktu menerima notifikasi
